Ir al inicio de sesión

Te invitaron a usar este cuestionario. Elige un usuario y una contraseña. Tu cuenta servirá para resolver preguntas y no tendrá permisos de administración.

Entre 3 y 32 caracteres: letras, números, punto, guion o guion bajo.
Mínimo 12 caracteres y variados. Una frase larga funciona bien. Nadie puede recuperarla si la pierdes.

Conexión con GitHub

  1. Abre GitHub con el botón de abajo. Ya viene con el nombre y el permiso Contents: Read and write.
  2. En Repository access elige Only select repositories y marca cuestionario-gastroenterologia.
  3. Presiona Generate token, copia el token y pégalo aquí.
